# Mes decks Commander

Ce dossier contient mes decks Magic Commander (papier). Chaque deck a sa fiche dans `decks/`.

- Pour tout ce qui touche à un deck, suis le skill **commander-coach** : il dit comment
  travailler avec moi et comment tenir les fiches.
- Avant d'analyser un deck qui a déjà une fiche, relis-la en entier.
- Le serveur **mtg** (texte des cartes, prix, combos, EDHREC, règles) est déclaré dans
  `.mcp.json` ; **deck-wizard** est installé comme skill.
